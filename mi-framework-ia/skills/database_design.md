# Skill: Database Design

## Propósito
Diseñar la estructura de datos del sistema.

## Tecnología propuesta
SQLite.

## Entidades principales
- Usuario
- Cliente
- Vehículo
- Sede
- Cita
- Servicio
- Instalador
- Inventario
- Consumo de material
- Pago

## Proceso
1. Analizar requisitos.
2. Identificar entidades.
3. Definir relaciones.
4. Definir claves primarias y foráneas.
5. Evitar duplicación innecesaria.
6. Validar el modelo contra las historias Must.
