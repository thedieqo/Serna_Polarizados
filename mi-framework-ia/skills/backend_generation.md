# Skill: Backend Generation

## Propósito
Generar propuestas para el backend de Serna Polarizados.

## Stack
Python + Flask + SQLite.
## Proceso
1. Leer requisitos Must.
2. Identificar entidades y reglas de negocio.
3. Definir endpoints necesarios.
4. Implementar lógica por capas.
5. Validar datos.
6. Manejar errores.
7. Proponer pruebas.

## Restricciones
- No inventar requisitos.
- No exponer credenciales.
- Mantener arquitectura monolítica en capas.
- El código debe ser revisado antes de aceptarse.
