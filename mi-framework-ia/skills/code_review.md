# Skill: Code Review

## Propósito
Revisar críticamente código generado con apoyo de IA.

## Verificaciones
- Cumple requisitos.
- Respeta arquitectura.
- Código legible.
- Validaciones correctas.
- Manejo de errores.
- Sin credenciales expuestas.
- Sin funcionalidades inventadas.
- Coherencia frontend/backend/base de datos.

## Salida
Problema | Impacto | Corrección recomendada

## Regla
No aprobar código únicamente porque compile.
